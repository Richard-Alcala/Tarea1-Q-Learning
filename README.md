# Tarea 1 — Q-Learning Grid World

A browser-based Q-Learning simulation built with TypeScript. An agent learns to navigate a 5×5 grid, finding food (+1) while avoiding traps (−1).

💻 **Repository:** [https://github.com/Richard-Alcala/Tarea1-Q-Learning](https://github.com/Richard-Alcala/Tarea1-Q-Learning)

---

## Running Locally

### Option 1 — Clone the repository

```bash
git clone https://github.com/Richard-Alcala/Tarea1-Q-Learning.git
cd Tarea1-Q-Learning
```

### Option 2 — Download ZIP

1. Go to [https://github.com/Richard-Alcala/Tarea1-Q-Learning](https://github.com/Richard-Alcala/Tarea1-Q-Learning)
2. Click **Code → Download ZIP**
3. Extract the ZIP and open the folder in your terminal

### Install dependencies & build

```bash
npm install
npm run build
```

### Serve locally

```bash
npx serve .
```

Then open [http://localhost:3000](http://localhost:3000) in your browser.

## How it works

The agent uses **Q-Learning** (Reinforcement Learning) with an ε-greedy policy:

| Parameter | Value |
|---|---|
| Learning rate (α) | 0.1 |
| Discount factor (γ) | 0.9 |
| Exploration rate (ε) | 0.2 |
| Reward — Food | +1.0 |
| Reward — Trap | −1.0 |
| Reward — Empty step | −0.01 |
