Tarea 1 - Q-Learning Grid World
================================

A browser-based Q-Learning simulation built with TypeScript. An agent learns to navigate a 5x5 grid, finding food (+1) while avoiding traps (-1).

Repository: https://github.com/Richard-Alcala/Tarea1-Q-Learning

---

RUNNING LOCALLY
---------------

Option 1 - Clone the repository:

    git clone https://github.com/Richard-Alcala/Tarea1-Q-Learning.git
    cd Tarea1-Q-Learning

Option 2 - Download ZIP:

    1. Go to https://github.com/Richard-Alcala/Tarea1-Q-Learning
    2. Click Code -> Download ZIP
    3. Extract the ZIP and open the folder in your terminal

Install dependencies & build:

    npm install
    npm run build

Serve locally:

    npx serve .

Then open http://localhost:3000 in your browser.

PROJECT STRUCTURE
-----------------

    src/
        gridworld.ts   # Q-Learning agent & environment logic
        main.ts        # Rendering & UI
    dist/
        bundle.js      # Compiled output (generated by build)
    index.html         # Main HTML page
    vercel.json        # Vercel deployment config
    tsconfig.json      # TypeScript config
    package.json       # Dependencies & scripts

---

HOW IT WORKS
------------

The agent uses Q-Learning (Reinforcement Learning) with an epsilon-greedy policy:

    Learning rate (a)      : 0.1
    Discount factor (y)    : 0.9
    Exploration rate (e)   : 0.2
    Reward - Food          : +1.0
    Reward - Trap          : -1.0
    Reward - Empty step    : -0.01
